# Fi-NeMo implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Call motifs from averaged ChromBPNet contributions and annotate REF/ALT motif changes.
**Architecture:** Keep DeepSHAP in the existing contribution image. Use a separate Fi-NeMo image for conversion, motif calls, and summaries. Two WDL entry points share the same motif-calling tasks.
**Tech stack:** WDL 1.0, Terra Cromwell, Python, HDF5, Fi-NeMo 0.41, PyTorch, micromamba, GitHub Actions.
**Spec:** `docs/superpowers/specs/2026-10-08-finemo-design.md`, approved in chat.

## Global constraints

Use explicit localized File inputs and safely quoted CLI arguments. Create file lists in tasks. No workflow-scope file writers, JSON argument wrappers, local Docker builds, or Terra submissions. Keep counts/profile and cell types separate. Images rebuild only on contained-script changes.

## Review focus

- Indels can shift motif coordinates: map allele bases to the reference; inserted bases remain explicit.
- Empty hit sets must produce a summary for every variant.
- Different TF matches must not multiply variant rows or replace motif IDs.
- Missing fold or row identity must fail before averaging.
- Every task must render cloud File inputs to readable local CLI paths.
